# 루키랩 정석 「세포편」

고등학교 『세포와 물질대사』의 탐구 셋을 한 흐름으로 이은 가상실험입니다.
**파일 하나, 설치 없음, 인터넷이 끊겨도 돕니다.** 휴대폰과 태블릿에서도 그대로 씁니다.

## 세 편이 한 질문의 세 조각

세포가 살아 있다는 것은 무엇인가.

| 부 | 실험 | 이 편이 답하는 것 |
|---|---|---|
| 1부 | 식물세포의 삼투 관찰 | 세포에는 안과 밖을 가르는 **막**이 있고, 막이 물의 출입을 고른다 |
| 2부 | 세포분획법으로 소기관 분리 | 안은 여러 **방(소기관)**으로 나뉘고 방마다 하는 일이 다르다 |
| 3부 | 효소의 작용 | 방 안에서 **일을 굴리는 것은 효소**이고, 조건이 속도를 정한다 |

편이 끝날 때마다 사수가 다음 질문을 던집니다.
세 편을 다 마치면 **종합 보고서**가 열려, 학생이 **직접 얻은 값으로 그려진 증거 카드**를
경계 / 구획 / 속도 세 칸에 맞추고 한 문단으로 묶습니다.

## 쓰는 법

주소를 열면 바로 시작합니다. **어느 편부터 해도 됩니다** — 잠그지 않고 권하기만 합니다.

- 진행은 **그 브라우저에만** 저장됩니다. 서버로 아무것도 보내지 않습니다.
- 그래서 **기기를 바꾸면 처음부터**입니다. PC 에서 하던 것이 휴대폰으로 따라오지 않습니다.
- 편 안의 「← 연구소」 를 누르면 언제든 첫 화면으로 돌아옵니다.
- 실험노트에서 세 편의 기록을 한 번에 복사할 수 있습니다.

## 만든 것

- 그림은 전부 코드로 그렸습니다. 외부 스크립트도, 그림 파일도 없습니다.
- 곡선과 수치는 **경향을 보이기 위한 학습용 모형 값**이고 실제 측정값이 아닙니다.
  화면에도 그렇게 적어 두었습니다. 수치를 외우게 하지 마세요.
- 용어는 교과서 표기를 따랐고, 교과서에 없는 설명은 화면에서 그렇게 밝힙니다.

그 위에 같은 연구소의 이야기를 얹었습니다.
